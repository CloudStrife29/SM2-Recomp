EnterElectro-Recomp - toolchain degli overlay di psxrecomp / psxrecomp's overlay toolchain

ITALIANO

Questi archivi servono a psxrecomp per compilare sul tuo PC, mentre giochi, i pochi pezzi di codice del gioco che non
sono stati compilati in anticipo (senza, quei pezzi vanno con l'interprete, piu' lento). Prima di ogni installazione il
launcher copia i due archivi di Python e di TinyCC nella cartella dell'installazione (.cache\overlay-toolchain\), dove
psxrecomp li cerca: cosi' psxrecomp non li scarica da internet (senza questi file li scaricherebbe da www.python.org e
download.savannah.gnu.org). psxrecomp controlla l'impronta SHA-256 di ogni archivio a ogni uso. Sono gli archivi
originali, non cambiati da EnterElectro-Recomp.

ENGLISH

psxrecomp uses these archives to compile on your PC, while you play, the few pieces of game code that were not
compiled in advance (without them, those pieces run in the interpreter, which is slower). Before every installation
the launcher copies the Python and TinyCC archives into the installation folder (.cache\overlay-toolchain\), where
psxrecomp looks for them: so psxrecomp does not download them from the internet (without these files it would
download them from www.python.org and download.savannah.gnu.org). psxrecomp checks the SHA-256 hash of every archive
each time it uses it. They are the original archives, not changed by EnterElectro-Recomp.

  source:    https://www.python.org/ftp/python/3.13.1/python-3.13.1-embed-amd64.zip
  license:   PSF License Agreement, plus the licenses of the libraries it includes: LICENSE.txt inside the archive
